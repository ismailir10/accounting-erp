# Roadmap: benchmark Zahir, Jurnal and Rillet against Buku

## Context
The owner asked for deep research on Zahir and Mekari Jurnal, as the Indonesian market benchmark, and on Rillet, as the AI
benchmark. The result should be a concise roadmap that compares the research with Buku's capabilities today and serves as the
basis for development from here on. ADR 0014's iterations I1–I5 are mostly built, so a new order is needed. This is a docs-only
change.

## Decisions
- The roadmap lives at `docs/roadmap.md` and is linked from the AGENTS.md "Read first" row, so every agent reads it before `/spec`.
- It keeps ADR 0014's thesis, spine, AI pattern and not-doing list. It replaces only the iteration order, with four phases: ready
  for an outside firm → proof with one firm → Rillet-grade AI pattern → Indonesian firm completeness.
- An ADR amending 0014 is written only after the owner approves. A proposal is not a decision.
- Competitor facts are dated October 2026 and labelled as vendor-sourced where they are.

## Acceptance criteria
- [x] Each competitor is researched with sources: pricing, banks, reconciliation, close, tax, AI, firm channel, weaknesses.
- [x] A comparison table of Zahir, Jurnal and Rillet against Buku today, with a verdict per area, checked against the code at
      `ec00b5b`.
- [x] A phased roadmap with an exit test per phase, a not-doing list, metrics, and the owner decisions needed.
- [ ] The owner approves the roadmap. Then an ADR amending 0014 is written.
